Travel guide Clone - HTML Prototype
Overview
This project is a front-end prototype of a Travel guide-inspired travel website built using HTML and CSS. The goal of this prototype is to replicate the core user interface and browsing experience of a travel review platform where users can discover destinations, hotels, restaurants, and attractions.

Features
Responsive homepage design
Navigation bar with search functionality
Hero section with featured destinations
Popular travel categories
Hotel and attraction cards
User review section
Destination recommendations
Footer
Mobile-friendly layout
Technologies Used
HTML5
CSS3
Font Awesome (optional)
Google Fonts (optional)
